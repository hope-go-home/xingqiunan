# TaskBench 使用指南

## 快速开始

### 1. 注册账号
打开浏览器访问 http://localhost:5173，点击"立即注册"，输入用户名和密码（至少6位）。

### 2. 创建第一个任务
进入"任务管理"页面，填写任务名称（如"处理季度报表"），选择任务类型，点击创建。

### 3. 与 AI 对话
进入"AI 对话"页面：
- **普通模式**：直接聊天，AI 逐字回复
- **Agent 模式**：AI 自动调用工具完成任务

试试这些指令：
- "帮我查一下杭州明天的天气"
- "解析一下 uploads 目录下的项目需求文档.txt"
- "把这段文字翻译成英文：智能任务自动化工作台"
- "创建一个人工智能相关的文档处理任务"

### 4. 使用知识库
- 添加文档：粘贴文本内容到知识库
- 搜索：输入关键词，AI 会语义匹配最相关内容
- 删除：移除不需要的文档

## 常见问题

Q: 为什么总览页任务数一直是 0？
A: 需要先创建任务。在任务管理页创建，或在 Agent 模式下说"帮我创建一个任务"。

Q: Agent 模式和普通模式有什么区别？
A: 普通模式就是普通聊天。Agent 模式下 AI 会先分析你的需求，然后自动选择并调用合适的工具（如查天气、搜知识库、创建任务等），最后用工具执行结果来回答你。

Q: 知识库搜索和普通搜索有什么不同？
A: 知识库基于 Chroma 向量语义检索，不依赖关键词精确匹配。比如搜"机器学习"也能找到"人工智能"相关的文档。
