# TaskBench 使用指南

## 快速开始

### 1. 注册账号
打开浏览器访问 http://localhost:5173，点击"立即注册"，输入用户名和密码（至少6位）。

### 2. 与 AI 对话
进入"AI 对话"页面：
- **普通模式**：直接聊天，AI 逐字回复
- **Agent 模式**：AI 自动调用工具完成任务，工具调用过程实时显示（天气/时间工具经 MCP 协议接入）

试试这些指令：
- "帮我查一下杭州明天的天气"
- "现在几点了？"
- "解析一下我上传的文档"
- "把这段文字翻译成英文：智能任务自动化工作台"

### 3. 使用知识库
- 添加文档：粘贴文本内容到知识库
- 搜索：输入关键词，AI 会语义匹配最相关内容
- 删除：移除不需要的文档

## 常见问题

Q: Agent 模式和普通模式有什么区别？
A: 普通模式就是普通聊天。Agent 模式下 AI 会先分析你的需求，然后自动选择并调用合适的工具（如查天气、搜知识库、创建任务等），最后用工具执行结果来回答你。

Q: 为什么上传的文件 Agent 看不到？
A: 文件按用户隔离存储在 uploads/user_{id}/ 目录，Agent 工具只允许访问自己的目录。文件在对话页通过 "+" 按钮上传，上传后可直接让 Agent 解析。

Q: 知识库搜索和普通搜索有什么不同？
A: 知识库基于 Chroma 向量语义检索，不依赖关键词精确匹配。比如搜"机器学习"也能找到"人工智能"相关的文档。
